# 工作台常用操作

Keywords: 数据集, 标注项目, 训练任务, 模型部署, 推理, 操作步骤, 创建, 上传, 导出

## 数据集

在“数据集”页面点击“新建数据集”，填写名称、数据类型和场景。创建后进入数据集详情页上传文件；文本、对话和 DPO 场景应按页面提示上传对应格式。数据集详情页会显示样本数量和场景信息。

## 标注项目

在“标注”页面点击“新建标注”，先选择标注大类，再选择具体标注类型和兼容的数据集。普通图像项目使用检测、分类、分割或姿态工作台；LLM/MLLM 使用对话工作台；DPO 使用偏好标注工作台。创建后点击项目进入标注页面。

## 训练任务

在“训练”页面创建训练任务，选择训练数据集和对应标注项目，再配置基础模型、训练轮数、输入尺寸、设备和增强参数。提交后在任务详情查看排队、运行、后处理、完成或失败状态；失败时先查看任务日志和错误信息。

## 模型部署与推理

训练完成并注册模型后，在“部署”页面选择模型、设备和版本进行部署。部署成功后查看部署健康状态和推理 API 信息；调用记录与耗时可在部署详情中查看。部署不可用时先检查模型状态、部署服务健康状态和服务端日志。
